# DSA Practice

Day-by-day Data Structures & Algorithms practice, imported from the `LatihanDSA` repo.
One note per session (`sessions/DayN.md`), not per problem — see
`cbl-wiki/templates/dsa-session.md` for the format new sessions should follow.

Pattern concepts live in the shared `cbl-wiki/concepts/` folder (tagged `dsa`), since
the same pattern (e.g. [[two-pointers]]) can recur across many problems. See
[[dsa|the DSA hub]] in `maps/` for the full pattern → problem index.

This folder isn't a full CBL challenge (no `session.md`/`challenge.md` — there's no
Big Idea/Essential Question framing here, just deliberate practice logs). `questions/`
is here for parity with the other challenge folders, in case a CBL-style investigation
into a specific DSA topic is ever started.
