# Database vs. file

A database is a structured system for storing, organizing, and retrieving data efficiently. Unlike plain files, it lets many users read/write simultaneously without corruption, enforces validity rules, and searches millions of records in milliseconds. File = papers in a box; database = labeled filing cabinet with an index.
