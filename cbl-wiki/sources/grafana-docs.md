# Grafana docs

Official Grafana documentation. A Grafana dashboard is a set of panels giving an
at-a-glance view of related data; each panel queries a data source (e.g. Prometheus) and
renders charts/graphs. The community publishes prebuilt PostgreSQL dashboards you import
by ID.
